## Common Ground
In this challenge, we are given two public keys (n1, e1) and (n2, e2), where e1 and e2 are the same exponent, and the encrypted flag using server 1's public key.

To decrypt the flag, we would need the private key but to get that private key, we would need to find the prime factors of n1. We do receive two private keys, so they may have some relationships. It turns out they do have a prime factor shared. 

Therefore, knowing one prime factor p, we can get the other prime factor q, calculate phi = (p-1) * (q-1), and find the multiplicative inverse of e to get d to decrypt the flag.
```python
from Crypto.Util.number import *

# You got 2 servers, server 1 and 2. Their n values are n1 and n2 for their RSA public keys.

n2 = 66802175730510689232803383764638570684596820629057022223150141158574689647888405378354543615445845637113400341950083015338280283695833431079461873618787256886369500988563085380474310729158508089560692121241705063457833467436291162460244203843257813257227296016448809685592370410705552747100245860634296608887
e = 65537 # e is same for both servers
# The flag is encrypted with server 1's public key, that is (e, n1)
flag = "1ff8f25823146d45b070b7bd5269d0cfcdaa728ff50ffa148f8a55068ceb4a7c0dbd95f5ba67369f7b12c0112034bd2569830a9fa2d56331790069c9ddd5aa70d14c07f4761bc0cd6104eeb1a504a92521bc59ae6b44a75779ed0e6503dcaee5ef0824dd004a8ee5a101e802049a66ebbbda63ae20db2b749a121a7338734f70"

# Let's check if n1 and n2 has anything related
gcd = math.gcd(n1, n2)
print(f"GCD: {gcd}. Bit length: {gcd.bit_length()}")
print(f"It seems they do have a GCD. Is it prime maybe? {isprime(gcd)}")
print(f"With this case where they share a prime, we could compute the other prime number for n1 = p*q")
p = gcd
q = n1 // p # // for integer division, / for FP division 
if p * q == n1:
    print("p*q is equal to n1")
phi = (p-1) * (q-1)
d = pow(e, -1, phi) # Gets priv key of n1
decrypted_flag = pow(bytes_to_long(bytes.fromhex(flag)), d, n1)
print(f"p = {p}\nq = {q}\nphi = {phi}\nd = {d}")
print(f"Decrypted flag is: {long_to_bytes(decrypted_flag)}")
```
